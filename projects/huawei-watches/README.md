# HUAWEI Watches — هدية لكل جيل (vertical ad, 1080×1920, 88.6 s)

Motion-graphics pass over the presenter's edit `Hu.ad` (release `cc1212` in `azcm1/cc1212-footage.`).

## Rebuild

1. Download the release asset `Hu.ad` to `assets/source.mov`.
2. `python3 tools/trim.py --render` → `assets/aroll.mp4`, then `python3 tools/reopen.py` → `assets/aroll2.mp4` (opening re-cut: each of the first three shots carries its own line; flat-lay and gift box slowed with motion interpolation) (24 long pauses tightened to ~0.22 s, 3.8 s saved; the breath before «أحيانًا أحلى طريقة…» is kept).
3. `npx hyperframes preview` to edit, `npx hyperframes render -o renders/huawei-ad.mp4` to export.

## Layout

- `index.html` — footage with punch-ins on every pause-trim join, SFX bed.
- `compositions/hook|kids|d3|gt7|outro.html` — one graphics scene per chapter.
- `compositions/captions.html` — generated by `tools/gen_captions.py` from `assets/transcript.json`
  (script aligned to the VO by `tools/align.py` — no ASR model was reachable, so timings come from the VO's pauses anchored to the shot cuts).
- Copy lives in the HTML; accent colours per watch: Kids blue `#3b7bff`, D3 champagne `#e3c08f`, GT 7 green `#2fcb7b`.
- No music bed yet; SFX are Pixabay-licensed (see `assets/sfx/CREDITS.md`).
